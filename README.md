Este repositorio contiene la práctica de despliegue de la aplicación web estática **2048**, utilizando:

- **Docker** y un `Dockerfile` basado en Ubuntu con Nginx para servir la aplicación.
- **Docker Hub**, donde se publica la imagen generada.
- **Amazon EC2 (Ubuntu 22.04)**, como entorno de despliegue.
- **Docker Compose**, para orquestar el contenedor en la nube.
- **GitHub Actions**, configurado para automatizar la publicación de la imagen en Docker Hub en cada push al repositorio.

El objetivo de la práctica es demostrar el ciclo completo de construcción, publicación y despliegue de una aplicación web en la nube usando contenedores.
